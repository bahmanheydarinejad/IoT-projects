# دسته بازی لمسی بی‌سیم پلی‌استیشن و گیرنده مانیتورینگ تله‌متری با NRF24L01+PA+LNA

این پروژه یک سیستم کامل **کنترل از راه دور صنعتی و گیمینگ با برد ۱ کیلومتر** است که شامل دو واحد فرستنده و گیرنده مجهز به نمایشگرهای رنگی گرافیکی، پردازنده‌های مجزا و ماژول‌های پرقدرت تقویت‌شده رادیویی **NRF24L01+PA+LNA** می‌باشد:

1. **واحد فرستنده (Transmitter / Touch Gamepad):**  
   مبتنی بر برد **NodeMCU ESP8266** و **نمایشگر لمسی ۲.۸ اینچ TFT SPI** با طراحی تعاملی دکمه‌های دسته پلی‌استیشن (D-Pad، کلیدهای چهارگانه اکشن، L1، R1، Select و Start)، نشانگر زنده ارسال پکت و وضعیت آنلاین اتصال.
2. **واحد گیرنده (Receiver / Telemetry Monitor):**  
   مبتنی بر برد کم‌مصرف **Arduino Pro Mini مدل 3.3 ولت (8MHz)** و **نمایشگر رنگی ۱.۴۴ اینچ ST7735** که ماکت گرافیکی دسته بازی را به صورت زنده ترسیم کرده و کلیدهای فشرده‌شده را در لحظه با رنگ اختصاصی روشن می‌کند.

## 🛡️ معماری امنیت، پایداری و حذف کامل تداخل سیگنالی (Anti-Interference Architecture)

برای تضمین عدم تداخل با شبکه‌های وای‌فای، بلوتوث و سایر دستگاه‌های فرکانس ۲.۴ گیگاهرتز و جلوگیری از تداخل چند دستگاه مشابه، تمهیدات زیر پیاده‌سازی شده است:

1. **انتخاب کانال رادیویی ۱۱۵ (فرکانس 2.515 GHz):**  
   باند فرکانسی شبکه‌های Wi-Fi خانگی و اداری بین کانال‌های ۱ تا ۱۳ (فرکانس 2.412 الی 2.484 گیگاهرتز) محدود است. کانال ۱۱۵ کاملاً خارج از این بازه قرار دارد و از هرگونه افت سیگنال ناشی از مودم‌ها یا هات‌اسپات‌های موبایل در امان است.
2. **نرخ انتقال داده 250kbps (حداکثر برد و حساسیت):**  
   تنظیم چیپ روی ۲۵۰ کیلوبیت بر ثانیه، حساسیت گیرندگی را تا **-94 dBm** ارتقا داده و مقاومت در برابر نویزهای محیطی را به حداکثر می‌رساند.
3. **آدرس پایپ اختصاصی ۵ بایتی (`PSG01`):**  
   تنها ماژول‌هایی که این آدرس هگزادسیمال ۵ بایتی سخت‌افزاری را داشته باشند، بسته‌ها را فیلتر و دریافت می‌کنند.
4. **بایت‌های جادویی همگام‌سازی (Magic Bytes 0xA5, 0x5A) و شناسه شبکه (Network Token 0xC0DE):**  
   در هر سیکل، بسته‌ها با هدر جادویی و توکن شبکه ارسال می‌شوند تا حتی در صورت دریافت بسته‌های متفرقه از شبکه‌های NRF هم‌جوار، فوراً در سطح نرم‌افزار نادیده گرفته شوند.
5. **کنترل خطای دو لایه (Hardware CRC-16 + Software CRC-8):**  
   بسته‌ها ابتدا توسط سخت‌افزار NRF24 با CRC-16 بررسی شده و سپس تابع اختصاصی `calculateCRC8()` صحت تمام بایت‌ها را تأیید می‌کند.
6. **مکانیزم قطع اضطراری ایمن (Fail-safe Timeout):**  
   اگر به مدت بیش از ۳۵۰ میلی‌ثانیه هیچ پکت معتبری دریافت نشود، گیرنده وضعیت اتصال را `NO LINK` کرده و تمام خروجی‌ها و دکمه‌ها را به حالت پیش‌فرض (صفر) ریست می‌کند.

## 🔌 جداول پین‌اوت و سیم‌بندی هر دو واحد (Wiring Pinouts)

### ۱. واحد فرستنده: اتصالات به برد NodeMCU ESP8266

روی برد NodeMCU خطوط سخت‌افزاری SPI (پین‌های D5, D6, D7) بین نمایشگر، تاچ و رادیو مشترک هستند و انتخاب هر تراشه با پین CS اختصاصی کنترل می‌شود:

| شماره پین | نام پایه قطعه | ماژول متصل | پین متناظر NodeMCU | عملکرد و نوع سیگنال |
| :---: | :---: | :---: | :---: | :--- |
| **۱** | **TFT_CS** | نمایشگر ۲.۸ اینچ | **D1** (GPIO5) | فعال‌ساز تراشه تصویر ILI9341 |
| **۲** | **TFT_RST** | نمایشگر ۲.۸ اینچ | **D2** (GPIO4) | ریست سخت‌افزاری تصویر |
| **۳** | **TFT_DC** | نمایشگر ۲.۸ اینچ | **D3** (GPIO0) | انتخاب داده / فرمان تصویر |
| **۴** | **NRF_CSN** | رادیو NRF24 | **D4** (GPIO2) | انتخاب تراشه رادیو روی باس SPI |
| **۵** | **SCK / CLK** | نمایشگر + تاچ + رادیو | **D5** (GPIO14) | کلاک مشترک سخت‌افزاری HSPI |
| **۶** | **MISO / DO** | تاچ (T_DO) + رادیو (MISO) | **D6** (GPIO12) | خط داده ورودی مشترک پردازنده |
| **۷** | **MOSI / DIN**| نمایشگر + تاچ + رادیو | **D7** (GPIO13) | خط داده خروجی مشترک پردازنده |
| **۸** | **TOUCH_CS** | کنترلر لمسی (T_CS) | **D8** (GPIO15) | فعال‌ساز تراشه تاچ XPT2046 |
| **۹** | **NRF_CE** | رادیو NRF24 | **D0** (GPIO16) | فعال‌ساز ارسال/دریافت رادیو |
| **۱۰**| **VCC** | تمام ماژول‌ها | **3V3** | تغذیه ۳.۳ ولت مدار |
| **۱۱**| **GND** | تمام ماژول‌ها | **GND** | زمین مشترک مدار |

> ⚠️ **نکته تغذیه NRF24L01+PA+LNA:**  
> به دلیل جریان لحظه‌ای فرستنده (تا ۱۱۵ میلی‌آمپر در زمان ارسال PA)، حتماً یک **خازن الکترولیتی یا تانتالیوم ۱۰ الی ۱۰۰ میکروفاراد** دقیقاً بر روی پایه‌های VCC و GND ماژول رادیو لحیم کنید.

## 🎮 چیدمان دکمه‌های دسته بازی و قالب پکت داده

### کلیدهای تعریف‌شده در بیت‌ماسک ۱۶ بیتی (`buttons`):
- **جهت‌های D-Pad:** بالا (`BTN_UP`)، پایین (`BTN_DOWN`)، چپ (`BTN_LEFT`)، راست (`BTN_RIGHT`)
- **کلیدهای اکشن پلی‌استیشن:** مثلث سبز (`BTN_TRIANGLE`)، دایره قرمز (`BTN_CIRCLE`)، ضربدر آبی (`BTN_CROSS`)، مربع صورتی (`BTN_SQUARE`)
- **کلیدهای جانبی:** گوشواره چپ (`BTN_L1`)، گوشواره راست (`BTN_R1`)، `BTN_SELECT`، `BTN_START`

### ساختار بسته داده (`GamepadPacket`):
```cpp
struct GamepadPacket {
  uint8_t  magic1;      // 0xA5
  uint8_t  magic2;      // 0x5A
  uint16_t networkId;   // 0xC0DE
  uint8_t  sequence;    // 0-255 Rolling Counter
  uint16_t buttons;     // 16-Bit Bitmask of all 12 buttons
  uint8_t  crc8;        // CRC-8 Checksum
};
```
در هر چرخه انتقال (حداکثر هر ۴۰ میلی‌ثانیه یا بلافاصله پس از لمس هر کلید)، وضعیت کامل تمامی ۱۲ کلید درون این بسته ۷ بایتی با بالاترین سرعت ارسال می‌شود.
