ماژول نمایشگر 2.8 اینچ TFT لمسی SPI v1.2

SKU: LCD-01-280

نمایشگر تمام رنگی دارای ارتباط سریال SPI با کنترلر درایور ILI9341، تاچ پنل مقاومتی به همراه چیپ XPT2046 و سوکت کارت حافظه SD.

  • رزولوشن تصویر 320 x 240 (QVGA)
  • تراشه درایور LCD ILI9341 (SPI 4-Wire)
  • کنترلر صفحه لمسی XPT2046 (SPI Dedicated)
  • عمق رنگ 65K / 262K Colors (RGB565)
  • ولتاژ کاری 3.3V Logic Level

برد توسعه NodeMCU ESP8266 (CH340)

SKU: COM-03-009

برد مجهز به ماژول ESP-12E با پردازنده ۳۲ بیتی تنسیلیکا، حافظه فلش ۴ مگابایت، ارتباط وای‌فای داخلی و رابط سریال CH340.

  • پردازنده مرکزی Xtensa LX106 @ 80/160 MHz
  • حافظه فلش 4 MB SPI Flash
  • گذرگاه سخت‌افزاری SPI HSPI (D5=CLK, D6=MISO, D7=MOSI)
  • مبدل سریال به USB CH340G
  • سطح منطقی پایه‌ها 3.3V (غیر متحمل به 5V)

دیاگرام و جدول تطبیق اتصالات (Wiring Pinout)

چیدمان کاملاً منظم جهت اتصال با کابل‌های فلت نواری (Ribbon Cable): برای جلوگیری از گره خوردن یا ضربدری شدن سیم‌ها، پایه‌های کنترلی نمایشگر به گونه‌ای بازطراحی شده‌اند که پایه‌های ۳ و ۴ و ۵ نمایشگر (CS، RESET، DC) دقیقاً پشت سر هم به پایه‌های D1 و D2 و D3 روی برد NodeMCU وصل شوند. تمام پایه‌ها بر روی یک سمت برد NodeMCU متمرکز هستند.
پین پین ماژول نمایشگر ۲.۸ اینچ پین برد NodeMCU شماره GPIO دسته‌بندی سیگنال تطبیق با کابل فلت
🎀 دسته اول: کابل فلت ۸ تایی تصویر (پین‌های ۱ تا ۸ نمایشگر)
۱ VCC 3V3 - POWER (+3.3V) سیم اول فلت -> پایه 3V3 برد NodeMCU
۲ GND GND - GROUND (0V) سیم دوم فلت -> پایه GND چسبیده به 3V3
۳ CS D1 GPIO5 TFT CS سیم سوم فلت -> پایه D1 (انتخاب تصویر)
۴ RESET D2 GPIO4 RESET سیم چهارم فلت -> پایه D2 (پشت سر هم با D1)
۵ DC / RS D3 GPIO0 DATA / COMMAND سیم پنجم فلت -> پایه D3 (پشت سر هم با D2)
۶ SDI (MOSI) D7 GPIO13 HSPI MOSI سیم ششم فلت -> خط دیتای سخت‌افزاری D7
۷ SCK (CLK) D5 GPIO14 HSPI CLK سیم هفتم فلت -> خط کلاک سخت‌افزاری D5
۸ LED (BLK) 3V3 - BACKLIGHT سیم هشتم فلت -> تغذیه بک‌لایت 3V3 دائم روشن
🎀 دسته دوم: کابل فلت ۵ تایی تاچ (پین‌های ۱۰ تا ۱۴ نمایشگر)
۱۰ T_CLK D5 GPIO14 TOUCH CLOCK کلاک تاچ (مشترک با پایه D5 نمایشگر)
۱۱ T_CS D8 GPIO15 TOUCH CS فعال‌ساز تاچ (دقیقاً چسبیده به پین D7 روی برد)
۱۲ T_DIN D7 GPIO13 TOUCH MOSI ورودی دیتای تاچ (مشترک با پایه D7 نمایشگر)
۱۳ T_DO D6 GPIO12 TOUCH MISO خروجی قرائت مختصات تاچ (متصل به پین D6 بین D5 و D7)
۱۴ T_IRQ D0 (یا آزاد) GPIO16 TOUCH IRQ وقفه تشخیص لمس (اختیاری)
بررسی وضعیت پایه‌های بوت در چیدمان جدید (Boot Strapping Pins):
  • پایه D8 (GPIO15) برای TOUCH_CS استفاده شده است. این پایه به دلیل مقاومت پول‌داون داخلی نودام‌سی‌یو در شروع روشن شدن در سطح LOW می‌ماند و هیچ تداخلی با بوت ایجاد نمی‌کند.
  • پایه D3 (GPIO0) به DC نمایشگر متصل است که ورودی امپدانس بالا بوده و مقاومت پول‌آپ داخلی نودام‌سی‌یو آن را در زمان بوت HIGH نگه می‌دارد؛ بنابراین برد به اشتباه وارد مد دانلود نخواهد شد.

مراحل گام‌به‌گام اجرای پروژه (Step-by-Step Lab Protocol)

۱

سیم‌بندی مرتب با کابل فلت (Ribbon Cable)

طبق جدول اتصالات بالا، کابل فلت ۸ تایی تصویر را متصل کنید. پایه‌های ۳ و ۴ و ۵ نمایشگر (CS, RESET, DC) به صورت کاملاً متوالی و مستقیم به پایه‌های D1, D2, D3 برد NodeMCU وصل می‌شوند. سپس کابل فلت ۵ تایی تاچ را متصل کنید که پین فعال‌ساز تاچ به D8 (کنار D7) وصل می‌گردد.

۲

نصب کتابخانه‌های آردوینو (Library Installation)

نرم‌افزار Arduino IDE را باز کرده، از منوی Sketch > Include Library > Manage Libraries... سه کتابخانه رسمی زیر را جستجو و نصب فرمایید:

Adafruit GFX Library (توسط Adafruit) Adafruit ILI9341 (توسط Adafruit) XPT2046_Touchscreen (توسط Paul Stoffregen)
۳

تنظیمات برد و درگاه در منوی Tools

از منوی Tools > Board > ESP8266 Boards گزینه NodeMCU 1.0 (ESP-12E Module) را انتخاب نمایید. فرکانس پردازنده را روی 160 MHz (جهت بیشینه کردن سرعت رندر فریم‌ها) و Upload Speed را روی 921600 یا 115200 تنظیم فرمایید.

۴

کامپایل و آپلود برنامه تست

اسکتچ آماده شده (کد زیر) را باز کرده و دکمه Upload را بزنید. پس از اتمام آپلود، نمایشگر روشن شده و ابتدا بنچ‌مارک اشکال هندسی و سپس رابط کاربری بوم نقاشی لمسی لود می‌شود.

۵

تست تعاملی و مشاهده خروجی در سریال مانیتور

پنجره Serial Monitor را با نرخ باودریت 115200 باز کنید. با قلم یا انگشت روی صفحه ضربه بزنید یا خط بکشید. مختصات خام مبدل ADC و مختصات کالیبره‌شده پیکسلی را به صورت بلادرنگ مشاهده خواهید کرد.

کد کامل اسکتچ تست (Arduino Test Sketch)

NodeMCU_ESP8266_TFT2.8_Touch.ino 
/**********************************************************************************
 * پروژه تست و راه‌اندازی ماژول نمایشگر 2.8 اینچ TFT لمسی SPI به همراه NodeMCU ESP8266
 * 
 * سخت‌افزارهای مورد استفاده:
 * 1. ماژول نمایشگر 2.8 اینچ TFT لمسی تمام رنگ SPI ورژن 1.2 (کد کالا: LCD-01-280)
 *    - درایور تصویر: ILI9341 (رزولوشن 320x240 پیکسل، 65K رنگ RGB565)
 *    - کنترلر لمسی: XPT2046 (ارتباط SPI مجزا)
 * 2. برد توسعه NodeMcu دارای هسته وای‌فای ESP8266 و مبدل CH340 (کد کالا: COM-03-009)
 * 
 * اتصالات پین‌ها (سیم‌بندی منظم و متوالی یک‌طرفه):
 * VCC -> 3V3  |  GND -> GND  |  CS -> D1 (GPIO5)  |  RESET -> D2 (GPIO4)
 * DC -> D3 (GPIO0)  |  SDI(MOSI) -> D7 (GPIO13)   |  SCK -> D5 (GPIO14)
 * LED -> 3V3  |  T_CLK -> D5 |  T_CS -> D8 (GPIO15)|  T_DIN -> D7 | T_DO -> D6 (GPIO12)
 **********************************************************************************/

#include <SPI.h>
#include <Adafruit_GFX.h>
#include <Adafruit_ILI9341.h>
#include <XPT2046_Touchscreen.h>
#include <EEPROM.h>

#define TFT_CS    D1    // GPIO5  -> متناظر پین 3 نمایشگر
#define TFT_RST   D2    // GPIO4  -> متناظر پین 4 نمایشگر
#define TFT_DC    D3    // GPIO0  -> متناظر پین 5 نمایشگر
#define TOUCH_CS  D8    // GPIO15 -> متناظر پین 11 نمایشگر

Adafruit_ILI9341 tft = Adafruit_ILI9341(TFT_CS, TFT_DC, TFT_RST);
XPT2046_Touchscreen ts(TOUCH_CS);

#define EEPROM_MAGIC 0x4341
const int CALIB_P1_X = 30;
const int CALIB_P1_Y = 30;
const int CALIB_P2_X = 290;
const int CALIB_P2_Y = 210;

int cal_p1_rawX = 700;
int cal_p1_rawY = 3400;
int cal_p2_rawX = 3400;
int cal_p2_rawY = 600;
bool cal_swapXY = true;

bool getTouchCoordinates(int &screenX, int &screenY, int &rawX, int &rawY, int &rawZ) {
  if (!ts.touched()) return false;
  TS_Point p = ts.getPoint();
  rawX = p.x; rawY = p.y; rawZ = p.z;
  if (rawZ < 300) return false;

  int raw_h = cal_swapXY ? rawY : rawX;
  int raw_v = cal_swapXY ? rawX : rawY;
  int h1 = cal_swapXY ? cal_p1_rawY : cal_p1_rawX;
  int h2 = cal_swapXY ? cal_p2_rawY : cal_p2_rawX;
  int v1 = cal_swapXY ? cal_p1_rawX : cal_p1_rawY;
  int v2 = cal_swapXY ? cal_p2_rawX : cal_p2_rawY;

  long mx = (long)CALIB_P1_X + (long)(raw_h - h1) * (CALIB_P2_X - CALIB_P1_X) / (h2 - h1);
  long my = (long)CALIB_P1_Y + (long)(raw_v - v1) * (CALIB_P2_Y - CALIB_P1_Y) / (v2 - v1);

  screenX = constrain((int)mx, 0, tft.width() - 1);
  screenY = constrain((int)my, 0, tft.height() - 1);
  return true;
}

void setup() {
  Serial.begin(115200);
  tft.begin();
  tft.setRotation(1);
  tft.fillScreen(ILI9341_BLACK);

  ts.begin();
  ts.setRotation(0); // دریافت داده‌های خام بدون دستکاری کتابخانه

  EEPROM.begin(64);
  // بارگذاری ضرایب کالیبراسیون از EEPROM در صورت وجود...
  initUserInterface();
}

void loop() {
  if (Serial.available()) {
    char c = Serial.read();
    if (c == 'c' || c == 'C') runTouchCalibration(); // اجرای ویزارد کالیبراسیون
  }
  // پردازش لمس و ترسیم بوم...
}

راهنمای جامع عیب‌یابی و پرسش‌های متداول (Troubleshooting)

۱. صفحه نمایش پس از روشن شدن کاملاً سفید است و تصویری دیده نمی‌شود
سفید بودن صفحه نشان‌دهنده روشن بودن بک‌لایت اما عدم دریافت دستورات اولیه توسط کنترلر ILI9341 است:
۱. سیم‌های خطوط SCK (D5)، MOSI (D7)، DC (D1) و CS (D8) را از نظر قطعی یا جا به جا بودن بررسی کنید.
۲. پین RESET (D0) را بررسی کنید. می‌توانید برای تست، این پین را مستقیماً به پایه RST برد نودام‌سی‌یو وصل کنید.
۳. اطمینان حاصل کنید کتابخانه Adafruit_ILI9341 به درستی نصب شده باشد.
۲. تصویر به درستی نمایش داده می‌شود اما صفحه لمسی هیچ پاسخی نمی‌دهد
۱. مطمئن شوید پین T_CS به D2 و پین T_DO حتماً به D6 (MISO) وصل شده باشد (اگر T_DO وصل نباشد، پردازنده نمی‌تواند مختصات را بخواند).
۲. اطمینان حاصل کنید پین‌های T_CLK و T_DIN به ترتیب با پین‌های D5 و D7 مشترک شده باشند.
۳. در کد برنامه، مقدار شرط فشار تاچ (rawZ < 300) را بررسی کنید؛ لمس مقاومتی نیاز به فشار ملایم ناخن یا قلم مخصوص (Stylus) دارد.
۳. جهت حرکت قلم با جهت ترسیم روی صفحه برعکس است (وارونگی محورها)
به دلیل تفاوت‌های جزئی در چرخش سنسور لمسی در پارت‌نامبرهای مختلف، در بالای فایل اسکتچ متغیرهای زیر تعبیه شده‌اند:
- اگر حرکت چپ و راست برعکس است، INVERT_TOUCH_X را برابر true قرار دهید.
- اگر حرکت بالا و پایین برعکس است، INVERT_TOUCH_Y را برابر true قرار دهید.
- اگر محور افقی و عمودی جا‌به‌جا شده‌اند، SWAP_TOUCH_XY را فعال فرمایید.
۴. برد NodeMCU مدام ریست می‌شود و پیغام خطای Watchdog Timer می‌دهد
پردازنده ESP8266 دارای تایمر نگهبان سخت‌افزاری (WDT) است. در صورتی که حلقه‌های برنامه بدون تاخیر اجرا شوند، این خطا رخ می‌دهد:
۱. در انتهای تابع loop() حتماً از delay(10); یا yield(); استفاده فرمایید تا تسک‌های پشت صحنه سیستم عامل وای‌فای فرصت اجرا پیدا کنند.
۲. تغذیه برد را از درگاه USB پایدار تأمین کنید. جریان مصرفی کل حدود ۱۲۰ میلی‌آمپر است و افت ولتاژ پورت می‌تواند موجب Brownout Reset شود.
